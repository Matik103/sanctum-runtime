# Security

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes (preview) |

## Reporting a vulnerability

**Do not** open a public GitHub issue for security-sensitive reports.

Email or DM the maintainers (see GitHub profile [@Matik103](https://github.com/Matik103)) with:

- Description and impact
- Steps to reproduce
- Affected version / commit

We aim to acknowledge within 72 hours.

## Scope

This policy covers the **open-source** code in [sanctum-runtime](https://github.com/Matik103/sanctum-runtime). Hosted enterprise / cloud products are out of scope until announced separately.

# Sanctum Runtime — Overview

Sanctum Runtime is open-core infrastructure that sits between AI reasoning and real-world execution.

## Core capabilities

- **Action verification** — approve, human-verify, or block before execution
- **Connect Agent** — low-code proxy gating for OpenAI-compatible providers plus SDK/adapters for deeper integrations
- **Policy engine** — per-action rules (YAML or API), org-scoped in production
- **Audit trail** — correlation IDs, resolve workflow, webhooks
- **Local-first** — offline heuristics and Ollama risk scoring (MIT SDK)
- **Fleet control plane** — dashboard, API keys, marketplace adapters, billing
- **First-user pilot** — protect one real action in minutes, then expand to fleet policy
